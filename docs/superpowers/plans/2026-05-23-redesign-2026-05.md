# Bibel.flogvit.no — Redesign 2026-05

Branch: `redesign-2026-05`

Design chat: `docs/redesign-2026-05/design-chat.md`

## Mål
Full visuell omarbeiding etter HTML-mocken, men med **full feature-parity** mot
dagens app. Eksisterende funksjonalitet som ikke har en åpenbar plass i mocken
skal mappes kreativt inn i nytt design (typisk via cmd-k, prefs-popover, eller
Utforsk-grid). Funksjonalitet i mocken som vi ikke har (multi-plan tabs, vers-popup
med 8 faner, ⌘K, fokusmodus, ⚙-popover) skal bygges.

## Harde krav som ikke kan brytes
1. **Copy-til-Word UX** må forbli minst like bra som i dag.
   `ChapterContent.tsx:131-208` lytter på `copy`-event, leser `data-verse-num` +
   `data-verse-text` attributter, og setter både `text/plain` (med valgfrie
   versnummer) og Word-vennlig `text/html` (Georgia 12pt). I ny `.vs`/`.vs-num`
   markup MÅ disse data-attributtene bevares og handleren fortsette å fungere.
   `copyVerseNumbers`-toggelen flyttes til prefs-popover.
2. **Alle 36 sider/ruter** beholdes — de re-skinnes, ikke fjernes.
3. **All brukerdata** (favoritter, notater, emner, leseplaner, manuskripter,
   sync, auth, offline) videreføres uendret. Kun presentasjonslaget endres.
4. **Tastatursnarveier** beholdes (Alt+Shift+F/E/N/… for nav, '/' og ⌘K for søk,
   F for fokus).

## Mapping av eksisterende funksjonalitet → ny design

| Eksisterende | Ny plass i designet |
|---|---|
| Header.tsx dropdowns (Mitt/Studier/Oversikt, 19 lenker) | Beholdes som dropdowns; også tilgjengelig via ⌘K-handlinger og Utforsk-grid |
| HomeContent.tsx (ContinueReading, DailyVerse, TodaysReading, TodaysReadingText, TodaysDay, BibleNavigation) | Hero (ContinueReading), Dagens-vers-kort (DailyVerse), Multi-plan tabs (TodaysReading + ReadingPlan), Lesetekster-kort (TodaysReadingText), Kategoriserte bok-grupper (BibleNavigation), Utforsk-grid (alt annet) |
| Header search input | ⌘K command palette (Phase 3) |
| ToolsPanel (font-size, bibel-version, secondary bibel, 9 toggles) | Prefs-popover (⚙) i lesevisningens app-header |
| ReadingSidebar (4 tabs: Timeline, Context, Resources, Lookup) | Vertikal scroll i `.read-context` med collapsible blokker; Lookup flyttes til ⌘K |
| LayoutModeButtons (normal/reading/panel) | Fokusmodus-knapp (F) + skjul/vis kontekstkolonne i prefs-popover |
| VerseDetails (cross-refs, prophecies, etc.) | Vers-popup `.vpop` med 8 faner |
| ChapterInsights | Tab/blokk i context-sidebar |
| Word4Word i kapittel | Tab "Grunntekst" i vers-popup |
| Parallels (ParallelsPage) | Beholder egen side + ny "Parallell"-strip under vers i lesevisning |

## Faser
Se TaskCreate-tasks for full liste. Kort:
1. Tokens + typografi (foundation)
2. Header / shared chrome
3. ⌘K command palette
4. Forside
5. Lesevisning: shell, TOC, chapter-rail, fokusmodus, prefs-popover
6. Vers-popup (8 faner + indikatorer)
7. Context sidebar
8. Parallell-strip
9. Mobil
10. Reskin øvrige 25+ sider
11. Copy-til-Word verifisering
12. A11y polish

Hver fase committes separat. Etter hver fase kjøres `npm run build` + manuell
sjekk i nettleser av minst 2 berørte sider. Mobil sjekkes på 375px viewport.

## Eksekvering
Iterativt i denne sesjonen — bruker kan avbryte mellom faser og redirigere.
